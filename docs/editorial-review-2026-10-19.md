## 編輯台如何挑選推薦閱讀

每篇文章的 `relatedSlugs` 可放入希望推薦的站內文章 slug，按陣列順序顯示。只能選 `data/listings.json` 的 stories 中既有文章，不是任意外部網址。

記者上稿範本：在 report-metadata.json 該篇設定加入：

```json
"relatedSlugs": ["26-chinese-spouses", "election-prepare"]
```

請依文章主題實際挑選，且不要推薦自己。舊示範 Docs 格式則在「相關文章」標題下，一段填一個 slug。轉換、檢查並重新發布後才會顯示。

## 試算表維護

新增的「導覽／下拉選單」欄為 JSON，例如 `[{"label":"謠言劇本","href":"/#rumors"}]`；「常見劇本／延伸閱讀連結」、「資訊卡／閱讀連結」填 HTTPS 或 `/reports/文章-slug`。

網站設定新增 site.donationUrl、hero.factsTitle、sections.initiative、sections.learning.resources。後兩項以 JSON 保存。建議先由新版資料執行 `npm run sheets:rows` 匯出完整欄位，再由工程端更新既有管理試算表。本次沒有修改 Google 原始文件及試算表；直接匯入舊試算表會失去未同步的新設定。

## 預覽方式

單檔預覽：下載並以 Chrome、Safari 或 Edge 開啟 review-preview.html。此檔包含目前文章及圖片，可操作下拉選單、文章與問答；使用系統字型。YouTube 播放與外站連結需要網路，檔案內導覽使用記憶體路由，重新載入會回首頁；不是公開網站網址。

完整專案預覽：`npm ci`、`npm run build:worker`、`npm run preview:worker`，開啟 http://127.0.0.1:8787/election2026/ 。
